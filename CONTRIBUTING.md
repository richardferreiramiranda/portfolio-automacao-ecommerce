# Como adicionar um projeto

Crie uma pasta numerada dentro de `projetos/`, usando nomes em minúsculas e separados por hífen.

Exemplo:

```text
projetos/02-normalizador-skus/
├── README.md
├── src/
├── tests/
└── exemplos/
```

O README do projeto deve explicar:

1. Qual problema a ferramenta resolve.
2. Quais são os requisitos.
3. Como instalar e executar.
4. Como configurar credenciais sem salvá-las no Git.
5. Quais são as limitações conhecidas.

Antes de publicar, remova dados reais de clientes, tokens, cookies, chaves e arquivos exportados de contas de produção.
